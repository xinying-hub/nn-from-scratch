Neural Network

I used this tutorial: https://www.youtube.com/watch?v=w8yWXqWQYmU&t=1698s which builds a neural network using just python and numpy

The dataset I used was: https://www.kaggle.com/datasets/oddrationale/mnist-in-csv which is the MNIST dataset in csv format which I was more comfortable with

Through this tutorial, I learned:
* forward propagation - weighted sum, using an activation function (ReLU)
* backward propagation - finding the error, going backwards to preceding layers to calculate how much to adjust the weights and biases
